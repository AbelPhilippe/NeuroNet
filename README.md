# NeuroNet

A C++ neural network project exploring deep learning, tensor operations, and neural network development using **LibTorch (PyTorch C++)**.

## Overview

NeuroNet implements a feedforward neural network using LibTorch. The current implementation demonstrates the definition of fully connected layers, tensor reshaping, activation functions, and log-probability computation.

The project is intended as a foundation for experimenting with neural network architectures, model training, and C++ machine learning integrations.

## Technologies

- **C++** — Core implementation
- **LibTorch** — PyTorch C++ API for tensor operations and neural networks
- **CMake** — Build system
- **ONNX Runtime** — Available for future model inference integration

## Architecture

The current neural network consists of:

1. **Input:** Grayscale images with dimensions `28 × 28`.
2. **Flattening:** Reshapes each image into a vector of 784 features.
3. **Hidden layer:** Fully connected layer with 128 neurons and ReLU activation.
4. **Output layer:** Fully connected layer with 10 outputs.
5. **Log-Softmax:** Computes log-probabilities for the 10 output classes.

The network accepts batches of images and produces an output tensor with shape `[batch_size, 10]`.

## Build

### 1. Configure the project

```bash
cmake -S . -B build \
  -DCMAKE_PREFIX_PATH="$HOME/libs/libtorch"
```

### 2. Compile

```bash
cmake --build build -j2
```

### 3. Run

Use the executable generated by your CMake configuration. For example:

```bash
./build/NeuroNet
```

Adjust the executable name if it differs in `CMakeLists.txt`.

## Direct Compilation

For a simple implementation that uses LibTorch directly, you can also compile with `g++`:

```bash
g++ neuronet.cpp -o neuronet \
  -I "$HOME/libs/libtorch/include" \
  -I "$HOME/libs/libtorch/include/torch/csrc/api/include" \
  -L "$HOME/libs/libtorch/lib" \
  -Wl,-rpath,"$HOME/libs/libtorch/lib" \
  -ltorch -ltorch_cpu -lc10 \
  -std=c++20
```

Run it with:

```bash
./neuronet
```

This command assumes a CPU-enabled LibTorch installation at `$HOME/libs/libtorch` and that `main.cpp` does not require additional libraries.
